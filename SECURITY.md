# 🔒 Politique de Sécurité — Genova

## Versions supportées

| Version | Supporté |
|---------|----------|
| 1.x.x   | ✅ Support actif |
| < 1.0   | ❌ Non supporté |

## Signaler une vulnérabilité

Si vous découvrez une vulnérabilité de sécurité dans Genova, merci de nous en informer rapidement.

**Ne créez pas d'issue publique.** Envoyez un email à :

📧 **security@genova.ai**

### Notre engagement

- ✅ Accusé de réception sous **24h**
- ✅ Évaluation initiale sous **72h**
- ✅ Correction prioritaire selon la sévérité
- ✅ Notification après la correction

### Classification des vulnérabilités

| Niveau | Temps de correction |
|--------|-------------------|
| 🔴 Critique | < 24h |
| 🟠 Élevé | < 72h |
| 🟡 Moyen | < 7 jours |
| 🟢 Faible | < 30 jours |

## Bonnes pratiques

- Utiliser les dernières versions des dépendances
- Activer Dependabot pour les mises à jour automatiques
- Ne jamais commiter de tokens, clés API ou mots de passe
- Utiliser des variables d'environnement pour les secrets
- Activer l'authentification à deux facteurs (2FA) sur les comptes GitHub
