QUICK START
================================================================================

1. Install Dependencies:
   npm install @huggingface/inference

2. Setup Environment:
   Add HUGGINGFACE_API_KEY to .env.local
   (Get free key from https://huggingface.co/settings/tokens)

3. Initialize Database:
   npx prisma db push
   npx prisma generate

4. Start Development:
   npm run dev
   
Access at http://localhost:3000
